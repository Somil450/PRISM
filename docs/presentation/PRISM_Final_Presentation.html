The Verification Impasse: Cryptographic Hashes vs Physical Provenance
Motivation & Background Presenter: Tanush Bhootra
Limitations of Conventional Evidence Handling
  • NIST SP 800-86 Paradigm: Digital custody chains depend upon bit-level file hashes (SHA-256) to confirm transmission integrity.
  • The Provenance Blindspot: A valid SHA-256 digest confirms that zero bits were altered during transmission, but offers zero proof regarding whether the captured photons originated from physical camera reality or neural generators.
  • Evidentiary Vulnerability: A cryptographically untampered media container can readily enclose a fully fabricated synthetic persona.
Cross-Generator Brittleness of Monolithic CNNs
  • Pixel-Grid Overfitting: Legacy convolutional architectures (MesoNet, XceptionNet) frame forensics as static binary classification.
  • Catastrophic Decay: XceptionNet fine-tuned on FaceForensics++ drops from 99.26% down to 65.27% AUC when evaluated on Celeb-DF v2 (a 34% drop!).
  • Compression Quirks: Detectors memorize dataset-specific encoding artifacts rather than invariant physical laws.
PRISM: Decoupled Multi-Agent Forensic Architecture
System Architecture Presenter: Tanush Bhootra

Four Foundational Engineering Principles
  • Decoupled Micro-Agents: Organizes forensic analysis into eight specialized evaluators across independent physical domains, preventing cross-channel error cascading.
  • Dual-Stream Grounding: Couples semantic Vision Transformer tokens with low-level PRNU camera sensor noise residuals.
  • Evidential Calculus: Replaces naive averaging with Dempster-Shafer theory, explicitly bounding epistemic ignorance under degraded evidence.
  • Courtroom Auditability: Compiles verified error bounds, pixel heatmaps, and SHA-256 signed JSON reports compliant with NIST SP 800-86 and Federal Rule of Evidence 702.
Dual-Stream Representation: ViT-DoRA + Wavelet PRNU
Core Technical Innovation Presenter: Somil Jain
Semantic Stream: ViT-B/16 with DoRA
  • Vision Transformer Backbone: Pre-trained on ImageNet-21K with 196 non-overlapping 16x16 patch tokens projected to d=768.
  • Directional Adaptation (DoRA): Decomposes linear weights into magnitude vector m and directional matrix V.
  • 1.43% Trainable Fraction: Updates only 1.24M parameters out of 86.8M total, preventing catastrophic forgetting of visual priors.
  • Feature Manifold: Preserves low-level edge, gradient, and illumination representations across unseen synthesis engines.
Physical Stream: PRNU Sensor Noise
  • Hardware Silicon Invariant: Microscopic crystalline lattice variations in imaging sensors imprint a unique noise pattern on genuine captures.
  • Wavelet Extraction: Extracted via four-level Daubechies-4 wavelet decomposition followed by per-channel Wiener noise filtering: W = I - F(I).
  • Generator Blindspot: Neural generators lack camera sensor noise; synthetic patches instead carry periodic upsampling convolution residuals.
  • Embedding Fusion: Globally pooled to 512-D and projected to d=768 alongside the ViT class token.
The Eight Specialized Forensic Micro-Agents
Micro-Agent Ensemble Presenter: Somil Jain
1. Illumination Agent

Estimates 3D light vectors for facial ROI and scene using Sobel gradient integration; detects angle mismatches > 35 degrees.

2. Corneal Reflection Agent

Detects pupil specular glints on HSV V-channel; verifies binocular stereo geometry across both eyes.

3. rPPG Biological Vitality

Extracts dermal blood volume pulse across 32 frames using CHROM chrominance subspace. AI faces lack cardiovascular pulse.

4. Lip-Sync & Audio Agent

Correlates Mouth Aspect Ratio (MAR) with 64-channel log-mel acoustic energy envelope to expose voice reenactment desync.

5. Video Kinematics Agent

Dense Farneback optical flow detects frame-to-frame velocity jerks and inter-frame luminance flicker in face-swap seams.

6. Compression ELA Agent

Error Level Analysis (q=90) and 2D Hann-windowed FFT detect upsampling convolution grids and compression discontinuities.

7. Container Metadata Agent

Parses ISO/IEC 14496-12 atom trees and EXIF headers for encoder strings without reading file paths, preventing label leakage.

8. Spatial Mask Decoder

Four-stage transposed-convolution decoder maps cross-stream tokens into a 224x224 pixel tampering heatmap.

Mathematical Evidence Fusion: Dempster-Shafer Theory
Decision Calculus Presenter: Kulsum Malik
Figure 6: Belief-Plausibility intervals [Bel(T), Pl(T)] across media cohorts.
Evidential Fusion & Zadeh Paradox Resolution
  • Frame of Discernment: Θ = {Authentic, Tampered}. Power set 2Θ includes ∅, {A}, {T}, and compound element Θ.
  • Epistemic Uncertainty: Mass m(Θ) explicitly quantifies ignorance under degraded social media compression rather than forcing an arbitrary 50/50 probability.
  • Subjective Logic Mapping: m(T) = r·p / (r+W), m(A) = r·(1-p) / (r+W), m(Θ) = W / (r+W) with vacuous prior W = 2.
  • Zadeh Paradox Ceiling: Under extreme agent opposition (K → 1.0), classical combination yields degenerate outputs. PRISM bounds conflict at Kmax = 0.99.
  • Pignistic Verdict: Computes final pignistic probability with explicit uncertainty bounds: Authentic (< 0.35), Tampered (> 0.65), or Inconclusive.
